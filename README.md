# FinalAssesment

A modular React.js application converting the Brillance custom contract billing landing page using Vite and Tailwind CSS v4.

## Tech Stack
- React 19
- Vite 6
- Tailwind CSS v4

## Key Features
- Component-driven architecture (Header, Hero, Services, Features, Testimonials, Pricing, Footer)
- Reusable cards, badges, and standalone SVG icon components
- Dynamic data rendering from structured datasets
- Responsive layout for mobile, tablet, and desktop

## Getting Started

Install dependencies:
```bash
npm install
```

Run development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```
